工作原理

这个模拟器演示了 Claude Code Agent Loop 的核心机制：

  • 消息累积：每一步都向 messages[] 数组追加新消息，LLM 看到的是完整的对话历史
  • stop_reason 驱动：当 LLM 返回 tool_use 时循环继续；返回 end_turn 时循环终止
  • 工具分发：根据 LLM 输出的工具名称，路由到对应的工具实现
  • Subagent 隔离：子 Agent 拥有独立的 messages 数组，完成后仅返回摘要文本

场景说明

  • S01 基本循环：最简单的 Agent Loop，只使用 Bash 工具创建文件并验证
  • S02 多工具协作：展示搜索 -> 读取 -> 编辑的典型工作流
  • S04 Subagent 委派：主 Agent 创建子 Agent 处理研究任务，观察上下文隔离
